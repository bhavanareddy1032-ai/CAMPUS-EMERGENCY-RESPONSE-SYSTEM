## 🌟 Key Features
- **One-Click Rapid SOS Broadcast:** Instant reporting for Medical emergencies, Security breaches, Fire hazards, Women safety, and Infrastructure breakdowns.
- **Campus Location Mapping:** Targeted location selection across Library, Hostels, Science Labs, Cafeteria, and Sports grounds.
- **Live Incident Dispatch Feed:** Real-time visibility into active alerts with priority badges (`CRITICAL`, `HIGH`, `MEDIUM`).
- **Responder Dispatch & Resolution Workflow:** Actionable controls to assign patrols and verify resolved incidents.
- **24/7 Verified Helplines Directory:** One-tap calling to Security Control Room, Ambulance, and Anti-Harassment cell.
- **Real-Time Campus Safety Metrics:** Live tracker for active emergencies, average response time, and campus safety index.

## 🛠️ Technology Stack
- **Backend:** Node.js, Express.js, RESTful APIs, CORS
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3, FontAwesome
- **Deployment:** GitHub Pages (Static Edge CDN), Vercel Serverless, Render Web Services
- **Architecture:** Hybrid Network-First with Zero-Downtime Client-Side Fallback Engine
